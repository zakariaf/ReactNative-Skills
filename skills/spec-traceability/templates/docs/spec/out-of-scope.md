# Out of scope

This version does not build these, even when one looks helpful or a library makes it easy. Bringing
one into scope is a product decision: the reviewer changes its entry first.

## OOS-1 · Accounts and cloud sync

No sign-in, no server copy of the tasks. NN-1 keeps the app useful without them.

## OOS-2 · Shared lists

No list shared with other people, no comments, no assignment.

## OOS-3 · Home-screen widgets

No iOS widget and no Android app widget in this version.
