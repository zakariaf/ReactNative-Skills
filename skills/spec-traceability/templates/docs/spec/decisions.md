# Decisions

Open decisions carry a default: build with the default, name it in the report, and ask only when the
default stops working. A settled decision is never asked again.

## DEC-1 · How long Undo stays on screen

- Status: open
- Options: 4 seconds, 5 seconds, until the next action
- Default: 5 seconds

Used by REQ-2.

## DEC-2 · First day of the week in date pickers

- Status: decided
- Decided: follow the device locale

Used by REQ-3.
