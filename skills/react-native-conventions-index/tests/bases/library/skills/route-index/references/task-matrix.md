# Task to skills

Generated by `scripts/build-index.mjs` from `assets/index.json` and every skill's frontmatter. Do not edit it by hand: change the data (or a skill's description), then run `node ${CLAUDE_SKILL_DIR}/scripts/build-index.mjs --write`.

## Contents

- How to read a row
- Row rules
- The matrix

## How to read a row

Find every row that matches the task and load every skill in them before writing code: the first skill leads the work and the others each own one part of it (their rules and checks apply too). Several rows can apply: load the union. The note says what to add or watch for. A skill the developer names in the task is always loaded as well.

## Row rules

Every row whose lead is one of the "when" skills, or that loads one of the "anywhere" skills at any place, also loads every "require" skill (`check-index.mjs` rule `row-rule`).

| Rule | When the lead is | Or the row loads | Also load | Why |
|---|---|---|---|---|
| pair | `alpha-one` | - | `beta-two` | the alpha part is always checked with the beta feature |
| feature-check | `beta-two` | `beta-two` | `alpha-one` | the beta feature, wherever it appears in a row, is checked with the alpha part under it |
