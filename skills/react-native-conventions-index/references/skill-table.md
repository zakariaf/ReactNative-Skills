# Skill catalogue

Generated by `scripts/build-index.mjs` from `assets/index.json` and every skill's frontmatter. Do not edit it by hand: change the data (or a skill's description), then run `node ${CLAUDE_SKILL_DIR}/scripts/build-index.mjs --write`.

84 skills in 12 groups (plugins: `react-native` 78, `react-native-games` 6). Each row is the skill's own description: what an agent reads when it decides to load a skill. A skill marked (runbook) loads only when it is named.
