## Rules that must hold

9. Fields bind the React Native way: onChangeText, onBlur, ref.

Why: react-hook-form reads event.target.value, which a React Native change event lacks, so the field would hold undefined.

Install

Add the skills to your agent.

Start every task with react-native-conventions-index: it routes the task to the skills that apply and gives the build order.

install
# the marketplace, the core plugin, and the optional game skills
/plugin marketplace add zakariaf/ReactNative-Skills
/plugin install react-native@react-native-skills
/plugin install react-native-games@react-native-skills

Skills load on their own when a task matches; run one by name as /react-native:<skill> or /react-native-games:<skill>.

# the repository is a Codex plugin: .codex-plugin/plugin.json, skills in ./skills/
git clone https://github.com/zakariaf/ReactNative-Skills

Install it the way your Codex version adds plugins from a Git repository. The Codex manifest ships all 79 skills; the game skills load only for game tasks.

# the open skills CLI places skills where your agent reads them
npx skills add zakariaf/ReactNative-Skills
npx skills add zakariaf/ReactNative-Skills --skill forms-and-input

Then give your agent AGENTS.md: how to pick, load and report, plus the intent map.
